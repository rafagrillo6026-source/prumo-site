# Prumo · página de vendas e demonstração

Site público do Prumo (gestão de obras com 3D e portal do comprador).

- `index.html`, `style.css`, `app.js`: página de vendas
- `demo/`: demonstração 3D com dados fictícios
- `assets/`: vídeo e imagem do topo da página

Publicado pelo GitHub Pages (Settings → Pages → branch `main`, pasta `/ (root)`).
O código-fonte completo e os agentes ficam no repositório privado `prumo-agentes`, pasta `site/`.
